If you use ~rsx~ in your research, please cite the paper and the software.

#+begin_export rst
The site bibliography (Sphinx + sphinxcontrib-bibtex) also lists these works in
:file:`docs/source/references.bib` for formal :cite: roles when building the docs.
#+end_export

* Paper

Goswami R, Goswami R. /rsx: a high-performance streaming toolkit for RAD-seq
sex determination./ BMC Bioinformatics (2026).
https://doi.org/10.1186/s12859-026-06628-4

Preprint: arXiv:2606.06434. https://arxiv.org/abs/2606.06434

It extends the original RADSex workflow, which should also be cited when
relevant:

Feron R, et al. /RADSex: a computational workflow to study sex determination
using restriction site-associated DNA sequencing data./ Molecular Ecology
Resources, 2021. doi:10.1111/1755-0998.13360

* Software

The repository includes a =CITATION.cff=, so GitHub renders a "Cite this"
repository" button with formatted BibTeX and APA. The published artifacts are:

- =rsxcore= and =rsx-cli= (the =rsx= binary) on [[https://crates.io/crates/rsx-cli][crates.io]]
- =pyrsx= (Python bindings) on [[https://pypi.org/project/pyrsx/][PyPI]]

The BMC Availability section names version 0.2.8 and the version-independent
Zenodo deposit [[https://doi.org/10.5281/zenodo.20531538][doi:10.5281/zenodo.20531538]]
(this snapshot: [[https://doi.org/10.5281/zenodo.20531539][10.5281/zenodo.20531539]]).
That deposit is the software-and-reproducibility package used for the paper
figures and numbers.

* Reproducibility archive

Same Zenodo family. Cite the concept DOI so a later snapshot still resolves:

Goswami R, Goswami R. /Reproducibility package for rsx: a high-performance
streaming toolkit for RAD-seq sex determination./ Zenodo.
[[https://doi.org/10.5281/zenodo.20531538][doi:10.5281/zenodo.20531538]]

* BibTeX / BibLaTeX entries

Copy-paste ready entries (compatible with both classic BibTeX and BibLaTeX/biber).
The GitHub "Cite this repository" button (from =CITATION.cff=) can also emit
BibTeX/APA.

#+begin_export rst
.. tabs::

   .. tab:: rsx (BMC Bioinformatics)

      .. code-block:: bibtex

         @article{goswamiRsxHighperformanceStreaming2026,
           title         = {rsx: a high-performance streaming toolkit for {RAD-seq} sex determination},
           author        = {Goswami, Rohit and Goswami, Ruhila},
           year          = {2026},
           month         = sep,
           journal       = {BMC Bioinformatics},
           publisher     = {BioMed Central},
           doi           = {10.1186/s12859-026-06628-4},
           url           = {https://doi.org/10.1186/s12859-026-06628-4},
           eprint        = {2606.06434},
           archivePrefix = {arXiv},
           primaryClass  = {q-bio.GN}
         }

   .. tab:: RADSex reference

      .. code-block:: bibtex

         @article{Feron2021radsex,
           title   = {{RADSex}: a computational workflow to study sex determination using restriction site-associated {DNA} sequencing data},
           author  = {Feron, Romain and others},
           journal = {Molecular Ecology Resources},
           year    = {2021},
           doi     = {10.1111/1755-0998.13360}
         }
#+end_export

For the software, use the Zenodo concept DOI (https://doi.org/10.5281/zenodo.20531538)
or GitHub's Cite button / =CITATION.cff= (it can generate BibTeX, APA, etc.).
