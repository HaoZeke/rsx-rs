# Compute per-marker allele frequencies

Compute per-marker allele frequencies

## Usage

``` r
rsx_freq(table_path, output_file, min_depth = 1L)
```

## Arguments

- table_path:

  Marker depth table (TSV).

- output_file:

  Output path (TSV).

- min_depth:

  Minimum depth threshold.

## Value

The output path, invisibly.
