# Per-individual marker depth

Per-individual marker depth

## Usage

``` r
depth(x, ...)

# S3 method for class 'marker_table'
depth(x, popmap, ...)
```

## Arguments

- x:

  A
  [marker_table](https://haozeke.github.io/rsx-rs/rsxr/reference/marker_table.md).

- ...:

  Passed to
  [`rsx_depth()`](https://haozeke.github.io/rsx-rs/rsxr/reference/rsx_depth.md).

- popmap:

  Population map path.

## Value

A tibble of per-individual depths.
